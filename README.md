# 🍜 Ramen Ingredient List

A simple React project featuring a list of ramen ingredients, created to practice using the `useState` Hook and managing data with React.

## ✨ Features

- Display a list of ramen ingredients.
- Show ingredient images and names.
- Remove ingredients from the list.
- Manage the list using React's `useState` Hook.
- Import ingredient data from a separate data file.
